# Insight
- Nhóm "Champions" (864 KH) là tài sản cốt lõi, cần được ưu tiên giữ chân ngay lập tức.
- Gần 10% doanh thu ($£896K) bị hủy. Cần khẩn cấp điều tra nguyên nhân để tối ưu hóa quy trình.
- Công ty quá phụ thuộc vào thị trường UK ($7.3M); cần mở rộng các thị trường khác để giảm rủi ro.Tần suất mua (F) và Chi tiêu (M) ít liên quan ($r \approx 0.04$). 
- Cần tập trung vào chiến lược Tăng giá trị trung bình đơn hàng (AOV) cho mọi giao dịch.
